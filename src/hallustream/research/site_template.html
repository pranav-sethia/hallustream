Catch an AI making things up while it writes

HalluStream reads a language model's hidden states as each word is generated and flags the names, dates and titles it is making up. No second model, no web search, just 5% extra time.

Read the code Run it free in Colab

Built with PyTorch and Hugging Face Transformers on Qwen3-4B, GLiNER, Gemini as the fact checker, and Modal GPUs.

    How it reads the model

    When a model writes a fact it does not really know, its internal state looks different from when it does. A small linear classifier, trained on about 20,000 fact-checked answers, learns to read that difference from one middle layer.

    The model writes

    Qwen3-4B generates normally. Nothing extra is generated or looked up.

    Layer 21 is read

    Each new token's hidden state, 2,560 numbers, is taken from layer 21 of 36, the layer a sweep over all of them found best.

    The probe scores it

    One dot product per token. When a sentence ends, the details in it get a risk from their tokens.

    Risky details are flagged

    Names, dates, numbers and titles above the threshold light up, while the answer is still being written.

    Choose how cautious it is

    A risk is the estimated chance a detail is made up, and it holds up: details given 90–100% risk turned out false 93% of the time. Where to draw the line is a trade-off between catching more errors and wrongly flagging true facts. Measured on text never used to build it.

    Run it

    A pip package with a command line and a Python API. It needs a GPU or an Apple Silicon Mac for Qwen3-4B, or the free Colab notebook.

    # install pip install "hallustream[entities] @ git+https://github.com/pranav-sethia/hallustream" # ask, with likely made-up details highlighted as each sentence is checked hallustream "Tell me about A Caribbean Mystery."
    hallustream chat

    The same, in a conversation.

    hallustream score "question" answer.txt

    Check an answer the model already wrote.

    hallustream batch prompts.jsonl

    Check a whole file and get JSON lines back.

    Detector.from_pretrained("qwen3-4b")

    Or from Python: generate, score or stream.
